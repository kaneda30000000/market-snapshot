# 朝のスナップショット自動取得

## 仕組み
- GitHub Actions が平日 6:15 と 6:45（JST）に `snapshot.py` を実行
- 数値は検索ではなく、機械可読なデータ元（日経の指数公式CSV、財務省CSV、Yahoo Financeのチャートデータ、FRED、CNN）から直接取得
- 各項目に予備のデータ元があり、上から順に試す。全部だめな項目は数値を作らず「未取得」と書く
- 6:45 の再実行では、6:15 で取れた項目を失敗で上書きしない
- 1項目でも未取得があればジョブが「失敗」になり、GitHubから通知メールが届く
- 結果は `data/latest.json`（と日付別ファイル）に保存

## 初回設定（10分程度）
1. GitHubで**公開**リポジトリ `market-snapshot` を作成（公開にするのは、朝の定期タスクからトークンなしで読むため。中身は公開市場データのみ）
2. この一式（`.github/workflows/snapshot.yml` を含む）をそのままアップロード
3. リポジトリの Settings → Actions → General → Workflow permissions を「Read and write permissions」にする
4. Actions タブ → market-snapshot → Run workflow で手動実行し、ログで各項目の OK / NG を確認
5. NG の項目があれば、ログのエラー内容を貼ってもらえればデータ元を差し替えます
